# TirLink Signs / TirLink Check

Tiny fallback fonts (owner, 16.11.2026, faster site stage 3): only the signs
the app's own font (FreightLink Sans = Liberation Sans) does not have, so the
browser no longer downloads a 195 KB font from Google for them.

* TirLink Signs (Regular, Bold): ₺ ₼ ₽ ₾ — cut from **Noto Sans**
  (Copyright 2022 The Noto Project Authors, https://github.com/notofonts/latin-greek-cyrillic).
* TirLink Check (Regular): ✓ — cut from **Noto Sans Symbols 2**
  (Copyright 2022 The Noto Project Authors, https://github.com/notofonts/symbols).
